# User guide

For the people who publish or use curb and parking data: city curb teams publishing CDS, facility operators
publishing APDS, and app or enforcement teams reading both. No programming is needed for the publisher tasks;
you edit data your systems already publish.

| Page | For | What it covers |
|---|---|---|
| [Publishing links](publishing-links.md) | CDS and APDS publishers | How to declare that a curb zone and a garage belong together, step by step |
| [Using links](using-links.md) | Apps, enforcement, analysts | How to find the garage for a curb, nearby supply, and check a shared permit |
| Using the Civic District demo | Anyone | A click-through of the demo page with screenshots: `docs/user-guide/demo.md`, added with the demo in [PR #7](https://github.com/rneubauer/CDS2APDS/pull/7) (not merged yet) |

The rules these pages summarise are in the [link profile](../02-link-profile.md). Where a page and the profile
disagree, the profile is right; please report it.
